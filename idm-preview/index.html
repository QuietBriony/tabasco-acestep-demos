namima — IDM ambient prototype

アンビエント側から入るIDMの判定クリップ（各90秒・同じ種・同じ旋律）。全部 numpy/scipy 自己合成・決定論・ソルフェジオ絶対Hz音律（非ドレミ）。🎧推奨、iPhoneモノでも可。
3本は同じ旋律・同じパッドで、ビートの有無と種類だけが違います。聴いてほしいのは ①旋律が「サイレン」でなく「跳ねるフレーズ」に聞こえるか ②非ドレミの「ずれ」が気持ちいいか気持ち悪いか ③3本のどの方向で長尺を焼くか。 リードはピッチ固定（ポルタメント無し）、ビブラートは遅れて薄く入るだけです。

判定結果: C（idm）で長尺化 — 6:00 版

同じ種 (seed 174852)・144小節・96 BPM。32小節ごとに4小節のブレイクダウン、最後の8小節はアウトロ（ビート抜け・旋律はアンカー音のみ）。切り刻みの強度は 0.35 → 0.6 → 0.75 と後半ほど荒れる。
マスター WAV（48k/24bit）と iPhone 用 m4a は Google Drive の AI連携/Music/ に worker 納品と同じ形式（-master.wav / -iphone.m4a / -handoff.md）で置いてあります。下の3本は判定に使った90秒クリップ（据え置き）。

A — beatless（パッド＋旋律＋サブ＋レコードノイズ）

SAW 85-92 側。ビート無し。

B — soft（＋丸いキック / リム / スウィングしたハット）

Xtal 側。12小節目からビート、24-28小節でブレイクダウン。

C — idm（＋切り刻んだ2小節ブレイク）

Drukqs 側の入口。スタッター / 逆再生 / ラチェットは控えめ、8小節ごとにフィル。
構造（36小節・96 BPM）: 0-8 パッドのみ → 8 旋律イン → 12 ビートイン → 24-28 ブレイクダウン（旋律はアンカー音だけ）→ 28-36 全部戻る → フェード。 長尺版は判定後に同じ種から焼きます（Surface CPU・数十秒）。
